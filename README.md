### 🚀 核心研究與專案重點 (Featured Research & Projects)

#### 1. 🛡️ 跨資料源威脅情報串接與 EPSS 演化視覺化
- **情資整合**：自動化串接 NVD、CISA KEV 與 EPSS 資料源，量化跨期（2026 H1 vs. 2025 H2）漏洞增長趨勢與威脅指標。
- **動態視覺化**：使用 Python 自動化追蹤近 100 天 EPSS > 1% 之高危弱點，將演化趨勢動態渲染呈現。

#### 2. 🌲 漏洞管理鏈決策模型 (Vulnerability Prioritization Model)
- **智慧分級**：導入決策樹演算法，將大量 CVE 弱點收斂劃分為 `Critical`、`High`、`Monitor` 與 `Defer` 四種修補優先級。
- **實務效益**：協助資安防禦團隊有效過濾雜訊，精準聚焦需第一時間修補之實質高風險漏洞。

#### 3. 🎯 校內滲透測試實務
- 參與校園網路與系統之滲透測試演練，具備基礎弱點盤點與漏洞驗證實務經驗。
